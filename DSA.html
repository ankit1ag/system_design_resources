33 Algorithm Patterns — Java

Every Big Tech interview question maps to one of these patterns. Master these and no problem can surprise you.

01

TWO POINTERS

Two indices moving toward each other or in same direction. Use on sorted arrays to avoid O(n²) nested loops.

MNEMONIC
🏃‍♂️🏃‍♀️ "Two runners on a track"

One from left, one from right. They meet in the middle.

// Two Sum II - sorted array int left = 0, right = nums.length - 1; while (left < right) { int sum = nums[left] + nums[right]; if (sum == target) return; else if (sum < target) left++; else right--; }
EASY ARRAY STRING
Problems: Two Sum II, 3Sum, Container With Most Water, Valid Palindrome
02

SLIDING WINDOW

Maintain a window of elements. Expand right, shrink left when invalid. Avoid O(n²) subarray/substring checks.

MNEMONIC
🪟 "A moving window on a train"

You slide the frame — what's outside doesn't matter.

// Longest substring without repeat Map<Character, Integer> map = new HashMap(); int left = 0, max = 0; for (int r = 0; r < s.length(); r++) { if (map.containsKey(s.charAt(r))) left = Math.max(left, map.get(s.charAt(r)) + 1); map.put(s.charAt(r), r); max = Math.max(max, r - left + 1); }
MEDIUM STRING ARRAY
Problems: Longest Substring, Minimum Window Substring, Permutation in String
03

FAST & SLOW POINTERS

Floyd's cycle detection. Slow moves 1 step, fast moves 2. They meet inside a cycle. Perfect for linked list cycles.

MNEMONIC
🐢🐇 "Tortoise & Hare"

If there's a loop, the hare laps the tortoise.

// Detect cycle in linked list ListNode slow = head, fast = head; while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; if (slow == fast) return true; // cycle! }
EASYLINKED LIST
Problems: Linked List Cycle, Happy Number, Find Duplicate Number, Middle of LL
04

MERGE INTERVALS

Sort by start time, then merge overlapping intervals. Key insight: if cur.start ≤ prev.end → overlap.

Arrays.sort(intervals, (a,b) -> a[0] - b[0]); List<int[]> res = new ArrayList(); for (int[] i : intervals) { if (res.isEmpty() || res.get(res.size()-1)[1] < i[0]) res.add(i); else res.get(res.size()-1)[1] = Math.max(...[1], i[1]); }
MEDIUMSORTINGARRAY
Problems: Merge Intervals, Insert Interval, Meeting Rooms, Non-overlapping
05

BINARY SEARCH

Not just sorted arrays! Think: "Can I binary search on the answer?" Search space must be monotonic.

TEMPLATE — Never get it wrong
int lo=0, hi=n-1; while (lo <= hi) { // <= for exact match int mid = lo + (hi-lo)/2; // avoids overflow! if (check(mid)) return mid; else if (tooSmall(mid)) lo = mid+1; else hi = mid-1; }
EASY→HARDSEARCH
Problems: Search Rotated, Koko Bananas, Median of Arrays, Capacity To Ship
06

BFS (Level Order)

Queue-based. Explore level by level. Use for shortest path, minimum steps, level-order traversal.

Queue<TreeNode> q = new LinkedList(); q.offer(root); while (!q.isEmpty()) { int size = q.size(); // lock in level size! for (int i=0; i<size; i++) { TreeNode node = q.poll(); // process node if (node.left != null) q.offer(node.left); if (node.right != null) q.offer(node.right); } }
MEDIUMTREEGRAPH
Problems: Level Order, Binary Tree ZigZag, Rotting Oranges, Word Ladder
07

DFS (Backtracking)

Explore all paths. Make a choice → recurse → undo choice. Classic: permutations, subsets, combinations.

void backtrack(List res, List curr, ...) { if (baseCase) { res.add(new ArrayList(curr)); return; } for (int i=start; i<candidates.length; i++) { curr.add(candidates[i]); // choose backtrack(res, curr, i+1); // explore curr.remove(curr.size()-1); // undo } }
MEDIUMRECURSION
Problems: Subsets, Permutations, Combination Sum, N-Queens, Word Search
08

DYNAMIC PROGRAMMING — 1D

Break problem into subproblems. dp[i] = answer for first i elements. Fill bottom-up.

KEY QUESTION TO ASK
"What is dp[i] in terms of dp[i-1]?"
// Climbing stairs: dp[i] = dp[i-1] + dp[i-2] int[] dp = new int[n+1]; dp[0] = 1; dp[1] = 1; for (int i=2; i<=n; i++) dp[i] = dp[i-1] + dp[i-2];
MEDIUMDP
Problems: House Robber, Climbing Stairs, Decode Ways, Jump Game
09

DYNAMIC PROGRAMMING — 2D

dp[i][j] = answer for subproblem of size i×j. Knapsack, LCS, edit distance all use this.

// Longest Common Subsequence int[][] dp = new int[m+1][n+1]; for (int i=1; i<=m; i++) { for (int j=1; j<=n; j++) { if (text1.charAt(i-1)==text2.charAt(j-1)) dp[i][j] = dp[i-1][j-1] + 1; else dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]); } }
HARDDP
Problems: LCS, Edit Distance, Unique Paths, Coin Change II, Knapsack
10

UNION-FIND (Disjoint Set)

Track connected components. union() merges sets, find() finds root. Path compression + union by rank = nearly O(1).

MNEMONIC
🌳 "Family tree with a boss"

Everyone reports to one boss (root). Merging = merging families.

class UnionFind { int[] parent, rank; UnionFind(int n) { parent = IntStream.range(0,n).toArray(); rank = new int[n]; } int find(int x) { // path compression if (parent[x] != x) parent[x] = find(parent[x]); return parent[x]; } void union(int a, int b) { int ra=find(a), rb=find(b); if (rank[ra]>rank[rb]) parent[rb]=ra; else if (rank[ra]<rank[rb]) parent[ra]=rb; else { parent[rb]=ra; rank[ra]++; } } }
MEDIUMGRAPH
Problems: Number of Islands, Accounts Merge, Redundant Connection
11

HEAP / PRIORITY QUEUE

Use when you need to repeatedly get min/max. Top K elements, K-th largest, merge K sorted lists.

// Top K frequent elements PriorityQueue<int[]> minHeap = new PriorityQueue((a,b) -> a[1]-b[1]); for (var e : freq.entrySet()) { minHeap.offer(new int[]{e.getKey(), e.getValue()}); if (minHeap.size() > k) minHeap.poll(); }
MEDIUMHEAP
Problems: Kth Largest, Top K Frequent, Merge K Sorted Lists, Find Median
12

MONOTONIC STACK

Stack that stays sorted. Pop when current element breaks monotonicity. Classic: next greater element, histogram.

// Next Greater Element Stack<Integer> stack = new Stack(); int[] res = new int[n]; Arrays.fill(res, -1); for (int i=0; i<n; i++) { while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) res[stack.pop()] = nums[i]; // found NGE! stack.push(i); }
HARDSTACK
Problems: Next Greater Element, Largest Rectangle Histogram, Daily Temperatures
13

PREFIX SUM

Pre-compute cumulative sums. Range sum query in O(1). prefix[i] = prefix[i-1] + nums[i-1].

// Subarray sum = prefix[r+1] - prefix[l] int[] prefix = new int[n+1]; for (int i=0; i<n; i++) prefix[i+1] = prefix[i] + nums[i];
EASYARRAY
Problems: Subarray Sum Equals K, Range Sum Query, Product Except Self
14

HASH MAP / SET

Trade space for time. O(1) lookup. Count frequencies, detect duplicates, store visited states.

// Two Sum: complement lookup Map<Integer,Integer> seen = new HashMap(); for (int i=0; i<nums.length; i++) { int comp = target - nums[i]; if (seen.containsKey(comp)) return ...; seen.put(nums[i], i); }
EASYHASH
15

TREE DFS (Recursive)

Preorder/inorder/postorder. Pass extra state (min/max for BST validation, path sum, depth).

// Max depth — classic DFS int maxDepth(TreeNode root) { if (root == null) return 0; return 1 + Math.max( maxDepth(root.left), maxDepth(root.right)); }
EASYTREE
Problems: Max Depth, Path Sum, Validate BST, Diameter, LCA
16

TOPOLOGICAL SORT (Kahn's)

Process nodes with in-degree 0 first. Use for dependency ordering, cycle detection in directed graphs.

// Course Schedule int[] inDeg = new int[n]; Queue<Integer> q = new LinkedList(); for (int i=0; i<n; i++) if (inDeg[i]==0) q.offer(i); while (!q.isEmpty()) { int u=q.poll(); count++; for (int v : adj.get(u)) if (--inDeg[v]==0) q.offer(v); }
MEDIUMGRAPHDAG
Problems: Course Schedule, Alien Dictionary, Task Scheduler
17

TRIE (Prefix Tree)

Tree of characters. Each path = a word. O(L) insert/search where L = word length. Great for autocomplete, prefix search.

class TrieNode { TrieNode[] children = new TrieNode[26]; boolean isEnd; } // Insert: for each char → children[c-'a']
MEDIUMSTRING
Problems: Implement Trie, Word Search II, Add and Search Word
18

SEGMENT TREE

Range queries + updates in O(log n). Build once in O(n), then query/update efficiently. Use for range min/max/sum.

HARDTREERANGE
Problems: Range Sum Query (Mutable), Count Smaller After Self
19

GREEDY

Make the locally optimal choice at each step. Proof: "If we don't pick the greedy choice, we can swap without loss."

KEY QUESTION
"Is the greedy choice always safe?"

Sort first — greedy usually needs a sorted order.

MEDIUMOPTIMIZATION
Problems: Jump Game, Gas Station, Meeting Rooms, Task Scheduler
20

DIVIDE & CONQUER

Split into halves → solve each → merge. Base case is trivial. T(n) = 2T(n/2) + O(n) → O(n log n).

HARDRECURSION
Problems: Merge Sort, Quick Sort, Count Inversions, Median of Medians
21

CYCLIC SORT

For arrays with numbers in range [1..n]. Place each number at its correct index. O(n) time.

int i=0; while (i<nums.length) { int j = nums[i]-1; if (nums[i] != nums[j]) swap(nums, i, j); else i++; }
EASYARRAY
Problems: Missing Number, Find Duplicate, Find All Missing Numbers
22

BIT MANIPULATION

XOR, AND, OR, shifts. XOR of same = 0. Use for finding unique element, subsets, power of 2 check.

// Single Number (XOR trick) int res=0; for (int n: nums) res ^= n; // Hamming weight while(n!=0){count+=n&1; n>>>=1;}
EASYMATH
Problems: Single Number, Subsets via Bits, Counting Bits, Reverse Bits
23

GRAPH — DIJKSTRA

Shortest path with weighted edges. Use min-heap. Never revisit a settled node.

PriorityQueue<int[]> pq = new PriorityQueue((a,b)->a[1]-b[1]); pq.offer(new int[]{src, 0}); while(!pq.isEmpty()) { int[] curr=pq.poll(); if(visited[curr[0]]) continue; // relax neighbors... }
MEDIUMGRAPH
Problems: Network Delay Time, Path with Min Effort, Cheapest Flights
24

ISLAND / FLOOD FILL (DFS/BFS on Grid)

4-directional or 8-directional grid traversal. Mark visited by modifying grid or using boolean array.

int[][] dirs = {{0,1},{1,0},{0,-1},{-1,0}}; void dfs(int[][] g, int r, int c) { if (r<0||r>=g.length||c<0||c>=g[0].length||g[r][c]!=1) return; g[r][c]=0; // mark visited for(int[] d:dirs) dfs(g,r+d[0],c+d[1]); }
MEDIUMGRAPHGRID
Problems: Number of Islands, Max Area Island, Pacific Atlantic, Surrounded Regions
25

MULTI-SOURCE BFS

Start BFS from multiple sources simultaneously. Distance from nearest source computed in one pass.

MEDIUMBFSGRID
Problems: Rotting Oranges, 01 Matrix, Walls and Gates
26

MODIFIED BINARY SEARCH

Binary search on rotated arrays, infinite arrays, or "search on answer" problems.

MEDIUMBINARY SEARCH
Problems: Search in Rotated, Find Minimum in Rotated, Peak Element
27

TREE DIAMETER / PATH SUM

Compute answer through a node. At each node, combine left and right results. Global max updated at each node.

int maxDiam = 0; int dfs(TreeNode node) { if(node==null) return 0; int l=dfs(node.left), r=dfs(node.right); maxDiam = Math.max(maxDiam, l+r); // path thru node return 1+Math.max(l,r); // height returned up }
MEDIUMTREE
28

MATRIX — DP (Grid)

dp[i][j] depends on dp[i-1][j] and dp[i][j-1]. Classic: unique paths, minimum path sum.

MEDIUMDPGRID
Problems: Unique Paths, Min Path Sum, Longest Increasing Path, Maximal Square
29

STRING — PALINDROME EXPANSION

Expand from center for O(n²). Use Manacher's for O(n). Check both odd and even center expansions.

for(int i=0; i<n; i++) { expand(s, i, i); // odd length expand(s, i, i+1); // even length }
MEDIUMSTRING
Problems: Longest Palindromic Substring, Palindromic Substrings, Palindrome Partitioning
30

LINKED LIST REVERSAL

Reverse in-place with prev/curr/next pointers. Can reverse in groups of K.

ListNode prev=null, curr=head; while(curr!=null) { ListNode next=curr.next; curr.next=prev; prev=curr; curr=next; } return prev;
EASYLINKED LIST
31

KNAPSACK DP

0/1 Knapsack: each item used once. Unbounded: items reused. dp[i][w] = max value with i items, weight w.

// 0/1 Knapsack — iterate backwards! for(int w=W; w>=wt[i]; w--) dp[w]=Math.max(dp[w], dp[w-wt[i]]+val[i]); // Unbounded — iterate forwards! for(int w=wt[i]; w<=W; w++) dp[w]=Math.max(dp[w], dp[w-wt[i]]+val[i]);
HARDDP
Problems: Coin Change, Partition Equal Subset, Target Sum, Coin Change II
32

INTERVAL SCHEDULING

Sort by end time. Greedy: always pick the interval that ends earliest. Maximizes count of non-overlapping intervals.

MEDIUMGREEDYINTERVAL
Problems: Non-overlapping Intervals, Meeting Rooms II, Minimum Arrow Shots
33

BOYER-MOORE VOTING

Find majority element in O(n) time O(1) space. Count up for candidate, down for others. If count=0, switch candidate.

int candidate=0, count=0; for(int n:nums) { if(count==0) candidate=n; count += (n==candidate) ? 1 : -1; }
EASYVOTING
Problems: Majority Element, Majority Element II

// SPACE CONSTRAINTS

Memory constraint signals

  • "O(1) extra space" → In-place algorithm. Modify input. Cyclic sort, two pointers, Floyd's.
  • "Can modify input" → Mark visited by negating value. Great for cycle detection.
  • No constraint mentioned → Use a hash map freely. Memory is not the concern.
  • "Space optimized" → Usually 1D DP instead of 2D. Rolling array trick.
💡 Rolling Array Trick: If dp[i] only depends on dp[i-1], you only need 2 variables, not an array!

// STEP 3 — BRUTE FORCE TEMPLATE

Always Start Brute Force

Never skip brute force. Say it out loud in the interview. Then improve it.

Script: "The naive solution would be [describe in plain English]. That would be O([complexity]) time. Let me see if I can do better using [pattern]."

Brute Force Starters:

  • Array problem? → Try all pairs: O(n²)
  • String problem? → Try all substrings: O(n²) or O(n³)
  • Tree problem? → Try all paths: O(n²)
  • Graph problem? → BFS/DFS from every node: O(V·(V+E))
  • Decision problem? → Recurse all possibilities: O(2ⁿ)
// STEP 4 — OPTIMIZATION TRIGGERS

From Brute Force → Optimized

  • Repeated work? → Memoization / DP
  • Sorted input unused? → Binary Search or Two Pointers
  • O(n²) nested loops? → Sliding Window or HashMap
  • Repeatedly get min/max? → Heap
  • Repeated substring/prefix? → Trie
  • Graph connectivity? → Union-Find
  • Range queries? → Prefix Sum or Segment Tree
  • Optimal substructure? → Dynamic Programming
  • Make local choice? → Greedy
// THE BUD TECHNIQUE

Find the Bottleneck, Unnecessary Work, Duplicated Work

B — Bottleneck

What's the slowest part of your algorithm? Target that specifically. E.g., O(n log n) sort + O(n²) lookup = O(n²) overall. Fix the lookup.

U — Unnecessary Work

Are you computing things you don't need? E.g., checking all pairs when you only need one. Early exit, prune search space.

D — Duplicated Work

Are you solving the same subproblem multiple times? Cache it. This is where DP and memoization come from.

How to Dry Run — The Right Way

Dry running is executing your code mentally, line by line, with a small example. 80% of bugs are caught here — before the interviewer points them out.

// THE 5-STEP DRY RUN PROTOCOL

Protocol

1
Choose a small, non-trivial example

Not too small (edge case only), not too large (takes forever). 4-6 elements is ideal. Include at least one edge case (empty, single element, duplicates).

❌ Bad example: [1, 2]     ✅ Good example: [3, 1, 4, 1, 5, 9, 2]
2
Write out ALL variables in a table

Before execution, list every variable with its initial value. Draw the data structure (array boxes, tree nodes, stack).

i = 0
left = 0
right = 5
result = []
3
Execute line by line — no skipping

Go through every iteration of every loop. Update variable values with each step. When you hit a conditional, evaluate it explicitly with current values.

Say out loud: "i=0, nums[0]=3, sum=3+9=12, target=10, 12 > 10, so right--"
4
Verify invariants hold at each step

What should always be true? E.g., "left ≤ right", "window is always valid", "stack is always monotonic". Check it every iteration.

5
Check boundary conditions last

After the main example works, test: empty input, single element, all same elements, sorted input, reverse sorted, maximum constraint.

Array/String Problems

  • Are indices within bounds at all times?
  • Off-by-one? (< vs <=, 0-indexed vs 1-indexed)
  • What happens at i=0 and i=n-1?
  • Empty array input handled?
  • Single element input handled?

Tree/Graph Problems

  • Null node base case handled?
  • Are you modifying the tree when you shouldn't?
  • Graph: visited set updated before or after exploring?
  • Directed vs undirected — tracking right direction?
  • Disconnected graph handled?

// MNEMONICS FOR EACH PATTERN

TWO POINTERS
🏃 TWO RUNNERS

One from each end, they meet in the middle. If sum too big → move right runner left. Too small → move left runner right.

SLIDING WINDOW

// TEST YOUR PATTERN RECOGNITION

Pattern Recognition Quiz

Read the problem description and identify which pattern to use. This is the most important skill.

QUESTION 1
Given an array of integers, find two numbers that add up to a target. Array is NOT sorted. n ≤ 10⁵.
✅ Hash Map wins! Store each number's index. For each num, check if (target - num) exists in map. O(n) time. Two pointers also works but needs sorting first → O(n log n). Binary search needs sorted input too.
QUESTION 2
Find the longest substring without repeating characters. Return its length.
✅ Sliding Window! Classic variable-size window. Expand right pointer, if duplicate found → shrink left pointer until valid. Map stores last seen index of each char.
QUESTION 3
You have a list of courses [a, b] meaning "a must be taken before b". Can you finish all courses? (Detect if cycle exists)
✅ Topological Sort! Build a directed graph. If after Kahn's algorithm (process all in-degree 0 nodes), not all nodes are processed → cycle exists → impossible. DFS with state coloring also works.
QUESTION 4
Find the K-th largest element in an unsorted array. n ≤ 10⁶.
✅ Min-Heap of size K! Maintain heap of K elements. If new element > heap minimum → pop min, push new element. Final heap contains top K elements; root is K-th largest. Also: QuickSelect O(n) avg if asked for optimal.
QUESTION 5
You can climb 1 or 2 stairs at a time. How many distinct ways to reach stair n?
✅ 1D Dynamic Programming! dp[i] = ways to reach step i = dp[i-1] + dp[i-2]. This is literally Fibonacci. Optimal substructure: to reach step i, you came from i-1 or i-2. Only need 2 variables (space optimized).
